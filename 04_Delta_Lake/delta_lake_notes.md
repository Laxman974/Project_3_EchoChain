# Delta Lake

## Objective
To implement Delta Lake features using Databricks.

## What is Delta Lake?

Delta Lake is an open-source storage layer that provides reliable data storage and advanced data management capabilities for Apache Spark.

## Features

- ACID Transactions
- Schema Enforcement
- Schema Evolution
- Time Travel
- Data Versioning
- Faster Query Performance

## Operations Performed

### 1. Create Delta Table
- Created a Delta table from the transformed_products dataset.

### 2. Update
- Updated records in the Delta table.

### 3. Delete
- Deleted selected records from the Delta table.

### 4. Insert
- Inserted new records into the Delta table.

### 5. Time Travel
- Viewed previous versions of the Delta table using Delta Lake Time Travel.

## Advantages

- Reliable data storage
- Better performance
- Supports UPDATE, DELETE, and INSERT
- Version history and recovery
- Seamless integration with Databricks

## Tools Used

- Databricks
- Apache Spark
- Delta Lake
