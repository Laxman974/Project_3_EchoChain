# Databricks Setup

## Objective
To perform data analysis on laptop datasets using Databricks and PySpark.

## Steps Performed

1. Created a Databricks Free Edition account.
2. Created a new notebook named `Week2_Databricks`.
3. Uploaded the following datasets:
   - cleaned_products.csv
   - transformed_products.csv
4. Created tables in Databricks:
   - week2databrick
   - transformed_product
5. Loaded the transformed dataset using PySpark.
6. Performed the following operations:
   - Displayed first 5 records
   - Printed schema
   - Counted total rows and columns
   - Generated summary statistics
   - Analyzed RAM distribution
   - Analyzed SSD distribution
   - Calculated average, minimum and maximum price
   - Identified top expensive laptops
7. Saved notebook outputs and screenshots.
