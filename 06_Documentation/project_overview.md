# EchoChain Project Overview

## Project Objective

Analyze New Laptop and Refurbished Laptop datasets using Python, PySpark, Databricks, and Power BI to generate meaningful business insights through data processing and interactive dashboards.

## Technologies Used

- Python
- Pandas
- PySpark
- Databricks
- Power BI
- GitHub
